# 功能配置

1.0.0 新增主题草稿与纯色背景、视频多帧／区间／单帧取色、颜色锁定与恢复，以及现有／融合／液态玻璃三种材质。生成结果需明确应用／保存；WebGL 不可用时提示并回退，保留保存的选择。

CC98 专栏按首次访问读取十大、新帖、版面、个人概览、消息、只读会话与签到月历。新帖原始偏移上限 500，放大共享当前状态，桌面窄屏用切页呈现。发送、删除、标记已读与签到请前往原站。

## 导航与首页

默认按浙大、学术、实用工具、其它／关于本站两级组织原站导航，排除社交娱乐，工具组合并。学习和工具内的个人屏蔽及两个额外工具作为可管理规则保存，不删除原站数据。

默认容器只允许排序；默认层级关系固定。原站条目可在所属默认卡片内排序和屏蔽，不能改名、改 URL 或移出；自定义容器与条目可编辑。删除有内容的自定义容器前需指定迁移位置。编辑主界面时也可配置组件，计时组件支持页面提醒与系统通知，浏览器关闭期间按实际时间继续计算。

## 天气

在设置 → 信息源 → 和风天气填写自己的 `xxx.qweatherapi.com` 专属 API Host、API Key，随后查询并选择城市／区县。没有内置通用 Key。

界面使用城市查询、实时天气、逐日 3 天／7 天、逐小时 24 小时、分钟降水、预警与空气质量接口；账号权限、可用地区和计费由和风天气决定。不是所有地区都提供分钟降水或空气质量，缺失会标明。

主卡片和详情按层级加载；共享有效缓存与并发请求，不因切换页面重复获取全部天气。点击手动刷新可能产生新请求，费用由用户的 API 账号承担。

## 校内信息

- 浙大统一身份认证：填写本人学号和密码，获取本科课表、考试、学在浙大作业；仅有权限且取得有效课程时显示研究生信息。
- WebVPN：单独填写 WebVPN 用户名、密码，不自动复用统一认证账号。恢复连接可能顶替该账号的其他会话；验证码、二次验证由用户在官方页面完成。
- 空数据、来源失败和缓存会分别标明。考试只显示未来考试，课表详情显示学期总览，作业点击前往课程活动页。

## CC98

先配置 WebVPN，再使用设备代码授权。默认 Client ID 是公开应用标识，**不是密钥**，无需 Client Secret；每个用户必须使用自己的 CC98 账号确认授权。也可以填写自己创建的应用 ID，启用设备代码授权及 `cc98-api offline_access` 范围。

当前只验证维护者账号，未证明该应用允许所有 CC98 账号授权；若服务端因审核或用户限制拒绝，应使用获准的自有应用或等待维护者调整，不能将已有验证当作公共服务可用性保证。未读组件显示系统、提及、回复、私信计数；十大组件取 `hotTopic`，每条可直达帖子。

## 主题与数据

必应主题配色跟随新壁纸自动生成，不直接修改其配色；可创建主题副本。视频／图片主题保存在本设备，可调整裁切、颜色十六进制值、透明度、字体和动效。

「导出首页配置」迁移首页设置；「导出 Edge 主题」生成另行安装的浏览器静态配色主题，两者不是同一种文件。Edge 静态主题不会随每日壁纸自动更新，需重新生成安装。

导入配置覆盖首页配置，最多保存一份导入前配置副本；不会替换已保留的校内密码、天气 Key 或 CC98 令牌，也不会迁移信息缓存或本机文件授权。设置中的「数据」可下载或恢复副本。
