# 完整功能预览实施计划（2026-10-02）

依据：docs/implementation.md 与用户本轮确认。用户已授权记录并实现首版，交付后暂停；每轮修改后暂停。已验收 bin/mvp 保留，新包 bin/full-preview。

## 已确认范围

- 和风：用户自行填写专属 API Host、API Key；手选地点。城市查询、实时、每日、两小时分钟降水；支持失败、无覆盖和旧缓存。
- 校内：本科为主，参考 Celechron 分源接入课表、考试、学在浙大学生待办；研究生仅有权限且存在有效课程才呈现。研究生失败不能阻断本科。
- 用户批准扩展本地保存可自动读取的学号密码；重启后复用会话，失效自动认证；验证码、错误凭据须用户处理，不循环重试。凭据仅可信扩展页面录入，后台访问，不同步、不导出、不记录。
- 课表今天及前后日，真实起止时间、地点含可靠校区；进行中优先，其次未来，结束收纳。节次按来源作息映射，不能可靠映射标未确定。
- 考试未来14天及全部公布入口，无数据短空态；作业截止排序、无期限最后，不推测提交状态。
- 一言仅哲学 k，原文、原作者出处、hitokoto.cn 链接；每页面一次，切换不刷新，不过滤、不为去重请求；失败缓存标旧，无缓存显示不可用。
- 保留已验收UI、原站依赖与入口回退。外部失败覆盖对应卡片，绝不触发整页回退。

## 性能与缓存

主页面绘制前零外部信息请求。绘制后缓存先呈现，前台约1.5秒/空闲启动到期更新，提前进入次级则提高优先级。后台全局最多2个请求、多页合并在途工作、一次统一认证。实时20分钟、每日60分钟、降水10分钟；课表考试60分钟、作业15分钟。隐藏标签不新开定时任务，无首页不轮询。一言最低优先级；限流退避。研究生无权限会话记忆，重新登录/手动重试恢复探测，空课程低频重查。

## 实施任务与职责

1. providers/campus.js：CAS与本科/研究生/课程系统适配，规范数据，使用依赖注入请求；tests/campus.test.cjs 测试解析、时间、独立失败。研究公开源验证真实接口，不凭空捏造。
2. external-core.js、external-background.js：和风、一言、缓存调度、消息与凭据边界；tests/external.test.cjs 验证并发合并、退避、缓存、不泄露。
3. account.html/js/css：可信扩展页面输入校内及天气凭据，地点查询选择、登录/清除。原站仅获得脱敏状态。
4. ui/external.js、ui/script.js、content.js：绘制后延迟启动、次级真实卡片、状态、设置动作，安全文本渲染、来源链接。
5. manifest权限按实际域名限定，普通设置改后台代理以收紧local存储权限。新增原生能力不加第三方依赖。
6. 回归原21测试、新增逻辑测试、语法与打包一致性；能用浏览器时检查UI；真实凭据与用户Edge验收不得以mock测试代替。
