## 在 Edge 安装

1. 打开 `edge://extensions/`，关闭旧的“ZJUers 个人首页”及仍启用的新标签验证扩展，避免多个扩展同时跳转或增强原站。
2. 保持开发人员模式开启，选择“加载解压缩的扩展”，选择本项目的 `bin/full-preview` 文件夹。
3. 打开新的标签页。主页面仍从 zjuers.com 完整页面取得导航；空白处右键进入次级页面，角落齿轮进入设置。
4. 新目录可能对应新的扩展 ID，因此配置和偏好首次为空；旧版本中的数据仍留在旧扩展。以后审阅此版修改时，刷新同一安装目录即可。

回退：关闭此预览扩展，重新启用安装自 `bin/mvp` 的旧扩展。Edge 启动页已设置为 zjuers.com 的用户无需重新设置。

## 配置信息源

在设置中选择“配置账户”或“配置天气”，会打开独立扩展配置页。也可以从扩展详情进入“扩展选项”。无需在聊天中提供密码或 API Key。

- 校内：填写本科生学号、统一身份认证密码，选择“保存并连接”。分别查看课表、考试和作业的状态。研究生内容只在有权限并取得有效课程时出现。遇到验证码，按显示提示打开学校系统完成验证，再回到扩展重新连接。
- 天气：填写和风控制台给出的专属 API Host（`xxx.qweatherapi.com`）与 API Key，保存后搜索城市或区县、选择匹配地点。Key 已保存时留空可以保留，地点需要明确选择。
- 名句：无需凭据，使用一言哲学分类。先展示缓存，主要信息更新后请求一次；主次切换不换句，限流或反爬失败保留旧缓存并标注。

配置页的学号密码、天气 Key 保存到本设备的扩展本地存储，仅可信扩展上下文可读取，不同步、不导出。密码不会回填到表单；首页只接收脱敏配置状态。普通扩展存储并非安全凭据库。

## 审阅重点

- 主页面出现速度与原站遮罩、导航、搜索、视频和主次切换。
- 天气地点、实时温度、今日高低温、两小时降水、失败提示与更新时间。
- 今天及前后日课表：起止钟点、地点／校区、进行中和未来课程优先、已结束折叠；跨学期查询。
- 未来 14 天及全部已公布考试；作业截止排序、没有截止时间的任务置后。
- 重开页面、重启 Edge 后自动连接；断开单个来源时不影响其他卡片，断网时旧缓存明确标旧。
- 清缓存与退出清凭据的边界，以及名句原文、作者／出处和一言链接。

## 性能安排

主页面绘制前不请求外部信息；绘制后先读取缓存，约 1.5 秒／空闲时启动到期更新，提前进入次级页面则立即检查。网络全局最多两个并发，相同来源合并在途更新。实时20分钟、每日60分钟、降水10分钟、课表考试60分钟、作业15分钟。后台标签停止新增周期性刷新，已启动任务可结束；没有起始页时不持续轮询。一言等待本页主要更新结束后执行。

诊断入口位于配置页底部“加载诊断”，只记录来源名称、成功／失败和耗时，不记录账号、任务、Cookie、票据或响应正文。导出的诊断不能用于证明具体学校账号已成功登录，需实际卡片核对。

## 权限、依赖与验证边界

没有新增软件、插件或第三方依赖。新增 `webRequest` 用于读取本扩展研究生认证请求的临时跳转票据；站点访问包含和风专属域、一言及上述校内系统。校历沿用 Celechron 的公开 HTTP 服务，只发无凭据请求；校历不可用时不编造上课时间。

自动测试验证数据解析、凭据消息边界、缓存调度、取消、时间排序、主页面后的初始化与原入口回归。AI 浏览器工具仍报告 `nodeRepl.fetch request failed`，未完成真实 Edge 画面验证；没有真实 Key／学号，因此和风、学校认证和重启自动登录尚待本机配置后验证。研究生考试单页上限暂沿用 Celechron 的 100 项。
