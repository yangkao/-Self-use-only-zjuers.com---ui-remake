## 1. 目标、基础与边界

- 产品：供用户个人使用的 Microsoft Edge 首页／新标签页扩展，首次实现面向 Edge。
- 基础：`zjuers.com` 的完整页面，以及 `assets/qql04umt.zip` 中的“ZJUers 轻首页美化”。继续加载原站页面，在其上调整导航、视觉与交互；不另造一套离线导航站。
- 视觉参考：主界面参考 nightTab 的字体、栏目标题与整体秩序；导航仍使用 ZJUers 美化版的一类一卡片、小型文字链接。次级界面切换参考 `assets/2026-09-30 23-25-32.mp4` 所示青柠起始页效果；设置面板参考 `assets/nightTab设置界面.png`。参考 Bonjourr、Tabliss、Momentum 等只作为已完成的设计研究背景。
- 本项目实际改动：重组导航、替换视频壁纸、调整搜索引擎、增加固定问候、主次界面切换与侧边设置面板，并接入天气和浙大个人学业信息。移除必应每日壁纸及其设置。资讯功能不纳入；普通待办／自建日程不纳入。
- 交付物：`srcs/` 下的工程源码、`bin/` 下供审阅的阶段试用版、项目说明和验证记录。正式版本通过用户验收后，按项目规则整理和上传至用户届时指定的私有 GitHub 仓库。

## 2. 界面与功能规格

### 2.1 主界面

- 顶部以时间和搜索框为主。每次打开页面短暂显示一次“Yangkao”问候。
- 默认搜索引擎为 Bing。搜索框内提供引擎切换；设置页提供“默认搜索引擎”选项。移除百度、搜狗、360，其他保留引擎以美化包实际清单为依据核对。
- 保留原站导航内容及美化包分组整理，按已讨论的清单做删改：移除“社交 · 娱乐”；合并“实用工具 · A／B”，删除百度翻译、谷歌翻译、腾讯文档、百度文库，增加刘明野工具箱 `https://tools.liumingye.cn/#/` 和 Tuna `https://mirrors.tuna.tsinghua.edu.cn/`；“学习 · 影视”仅保留 MOOC、智慧树、学习强国。实施前从原站／美化包提取并保存导航对照清单，避免漏项和重复。
- 四个纵向排列、默认展开、可折叠的一级栏目：浙大、学术、实用工具、其它 · 关于本站。七张按内容自适应高度的二级卡片依次为：教学、信息化服务、其它；学术搜索 · 查重、学习；实用工具；其它 · 关于本站。页面允许纵向滚动；折叠状态可在设置中选择是否记忆。
- 不制作 nightTab 截图中的底部工具栏。低频设置不放在主界面。
- 仅使用扩展内置的 `assets/西行妖 60FPS.mp4` 副本，自动播放、静音、循环；无需暂停控件和静态后备画面。彻底移除壁纸切换及其设置。主题采用与视频匹配的深紫和樱花粉，主页面组件增加透明度，次级信息卡片和设置面板保持较实底色。
- 时间与搜索的字体、样式、交互和尺寸参照用户提供的 nightTab 截图及 `assets/nightTab搜索栏预览.mp4`，位置根据本页面布局调整。搜索引擎切换以搜索栏左侧小图标呈现。问候置于更上方以避免重叠；页面品牌与标签页使用 ZJUers 原站花形图标；卡片采用简约线条图标；删除操作提示和一级栏目序号。

### 2.2 次级界面与切换

- 在主界面空白处右键进入同页覆盖式次级界面；在次级界面除控件外的空白区域左键返回。点击卡片、按钮、链接和设置面板不触发返回。
- 切换时主界面内容先淡出，持续播放的视频背景转为模糊，次级内容淡入；返回时反向执行。顶部时间基本保持位置，主界面滚动位置保留。动效时长和模糊程度以预览实测调整。
- 次级界面包括天气、课表、近期考试、学在浙大作业及截止时间。四类信息按各自来源独立展示加载中、有数据、成功但无内容、连接失败与旧缓存状态；外部源失败提示覆盖对应控件位置，不误报为空数据。
- 后续接入阶段将课表、考试、作业栏的标题设置为跳转到对应信息源的链接，保持现有呈现形式。静态预览只展示标题。
- 天气卡片展示地点、当前天气状况与温度、今日最高／最低温、短时降水提示、数据源与更新时间。地点可设置；“杭州”是初始建议，尚待数据源选定时确认。近期无考试时以简短一行说明；考试源失败时明确标记失败和上次成功更新时间。
- 次级界面角落放齿轮入口。侧边展开的设置面板内左侧分类、右侧选项；点击面板外先关闭面板回到次级界面，再点击次级空白处才返回主界面。齿轮与面板位置不冲突。

## 3. 技术路径与待验证条件

1. **原站增强**：先阅读美化包 `manifest.json`、`src/content.js`、`src/content.css`、`src/background.js`，记录原站 DOM 依赖及已有逻辑。工程以其可复用部分为起点，在 `srcs/` 中维护新版本，不覆盖 `assets/` 原件。对原站 DOM 的观察与修改集中在适配模块，避免每个界面组件直接依赖易变的选择器。
2. **浏览器入口与失败回退**：目标是 Edge 启动和点击“+”时打开美化后的 `zjuers.com`，站点确实不可连接时显示 Edge 原生新标签页。启动页设置与扩展新标签页覆盖是不同机制；扩展能否可靠打开原生页、如何避免回退循环，须用最小 Edge 验证先确认。仅将导航失败、DNS／连接错误等可判定的原站不可达情况列为候选触发；页面加载慢、某个外部信息源失败或局部脚本错误均不得直接触发跳转。若原生回退不可实现，记录实测结果并与用户重新确定退路，不能悄悄改为扩展自建空白页。
3. **校内数据**：参考 Celechron 的登录与分源抓取思路，分别接入课表、考试、`courses.zju.edu.cn` 作业及截止时间。先判定本科／研究生所需来源、统一认证跳转、验证码、Cookie、扩展跨站请求权限和可达性；接口数据只用于当前用户展示。每源独立缓存最近成功结果及时间，失败时保留旧数据并标旧。学号／密码长期保存方式须在真实接入前单独选定并经用户确认；浏览器普通持久存储不得被称为安全凭据库，凭据不得进入同步备份、日志或导出文件。必要时使用仅本次浏览器会话有效的登录方案作为验证路径，但不能据此声称已经实现持久自动登录。
4. **天气**：选择可用、适合个人使用的数据源，核对地点、当前状况、当日高低温、短时降水是否都有数据，再确定请求权限与刷新间隔。缺少短时降水字段时应显示清楚，不伪造预测。
5. **存储**：普通偏好、缓存和凭据分别管理；确认容量、跨设备行为和清除边界。账号凭据不与普通设置混存。默认视频进入正式扩展包，不保存用户自选壁纸。
6. **依赖**：优先使用浏览器原生 API、现有美化包中的可用资源及简单 HTML／CSS／JavaScript。新增或更新依赖、安装辅助软件、修改系统环境均按 `AGENTS.md` 先列原因和替代方案，获用户同意后执行。
