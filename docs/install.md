# 正式版安装、升级与信息源配置

版本：0.2.0。正式包包含 manifest.json 的目录才是加载目录；不选择上级ZIP存放目录。

## 已安装当前通过版本

如果当前扩展来自 bin/full-preview，继续使用即可，正式包功能一致。不要只为目录名称重新安装，避免新扩展ID导致已保存凭据与偏好看起来丢失。本轮保持原安装目录与浏览器存储不变。

## 首次安装

1. 将 zjuers-home-0.2.0.zip 解压到固定位置，保留整个文件夹。
2. 打开 edge://extensions，关闭旧的同类首页扩展与项目验证扩展，避免同时跳转和增强。
3. 开启开发人员模式，点击“加载解压缩的扩展”，选择 zjuers-home-0.2.0 文件夹；其中应能看到 manifest.json。
4. 新建标签页，确认进入 zjuers.com 并显示个人页面。
5. 若希望启动Edge时打开该页，在Edge设置的“启动、主页和新建标签页”中选择打开指定页面，添加 https://zjuers.com/。浏览器设置由用户自行完成。

本轮交付为可解压加载的ZIP，不是商店发行或签名安装程序。

## 信息源

首页空白处右键进入次级页，点击齿轮，在天气／校内服务中打开配置页；也可从扩展详情打开“扩展选项”。

- 天气：和风控制台“设置”中的完整专属 API Host，例如 xxx.xy.qweatherapi.com；填写 API Key，先保存，再查询城市或区县并点击匹配地点。
- 校内：填写学号和统一身份认证密码，保存并连接。课表、考试、学在浙大分别显示状态。研究生系统无权限或无有效课程时不显示其内容。
- 名句：无需配置，使用一言哲学分类。作者与《来源》单独呈现在名句下方。

凭据保存在当前浏览器配置文件中本扩展的本机local存储，可供自动读取；不随ZIP携带，也不自动跨设备同步。密码与Key不会回填到输入框。已保存天气Key时留空可保留。普通扩展存储不是加密凭据库。

## 升级与恢复

- 同一目录更新文件后，在扩展管理页重新加载，再刷新已打开的zjuers.com页面；否则旧页面可能显示“扩展连接已失效”。
- 卸载扩展或改用新目录可能导致配置不能沿用。保留当前目录是最简单的升级方式。
- 清缓存保留凭据；退出校内账户清除扩展中的校内凭据及缓存；清除天气配置会删除对应配置和天气缓存。
- 要恢复旧MVP，停用当前扩展并启用本机bin/mvp。旧版不随正式ZIP提供。

## 常见情况

未配置、暂无数据、源不可用和旧缓存按控件位置标注。遇验证码时在学校网页完成验证后重新连接。配置页底部提供加载诊断，不记录密码、Key、任务正文或认证票据。

视频默认自动播放、静音循环，恢复可见时尝试恢复播放。浏览器节能或解码状态仍可能影响播放，诊断用于定位。原站网络错误回退机制与外部信息失败独立；外部来源失败不会关闭首页。
