# 正式版安装、升级与信息源配置

版本：0.3.1。选择包含 manifest.json 的文件夹加载。

## 已安装用户

保持当前扩展安装路径，在 `edge://extensions` 点击原扩展的重新加载按钮，再关闭旧首页标签、重新打开新标签。用户当前使用的 `bin/release/zjuers-home-0.2.0/` 已更新为 0.3.1，目录名称为了兼容保留。不要卸载重装或更换目录，以免原扩展 ID 和配置不能沿用。

## 首次安装

1. 解压 zjuers-home-0.3.1.zip 到固定位置。
2. 打开 edge://extensions，禁用其它会处理新标签页的项目扩展。
3. 开启开发人员模式，加载解压后的 zjuers-home-0.3.1 文件夹。
4. 在扩展详情开启“允许访问文件 URL”，以使用本机图片／视频壁纸。
5. 新建标签，确认进入原站及个人界面；Edge 启动页由用户在浏览器设置中指定 https://zjuers.com/。

不同目录的新安装可能获得不同 ID，不自动继承旧扩展的配置。ZIP 不含浏览器内的凭据或缓存。

## 信息源

空白处右键进入次级界面，齿轮打开设置。天气／校内服务通过独立扩展页面配置。

- 和风天气：完整专属 API Host、API Key，保存后查询地点并选择。
- 校内：学号和统一身份认证密码，保存并连接。研究生信息仅在有权限且有有效课程时出现。
- 一言：哲学分类无需配置，作者及《来源》单独呈现。

凭据在本机扩展 local 存储中自动读取，不跨设备同步，不随 ZIP 携带；普通扩展存储不是加密凭据库。清缓存保留凭据；退出校内账户会清除校内凭据和对应缓存。

## 主题与壁纸

主题卡片单击应用、右键重命名／创建副本／删除，默认主题不可删除或改名。本地壁纸填写完整绝对路径，原文件不被复制或长期缓存。预览取色生成整套配色，保存主题后下次打开恢复；路径失效时弹窗提醒并使用默认视频及配色。视觉参数即时预览，保存主题后持久化。问候名称及分时模板独立保存，模板使用 `{称呼}`。

Edge 配套主题在设置中下载 ZIP，解压并按其中 INSTALL.txt 手动加载；不会自动与首页切换同步。

## 常见情况

扩展更新后旧页面可能提示连接失效，关闭后重开。外部信息不可达、缓存过期和认证失效按原控件位置说明。浏览器节能可能影响视频播放；本机视频默认静音循环，恢复可见时尝试继续播放。原站连接失败回退与外部信息源失败互相独立。
