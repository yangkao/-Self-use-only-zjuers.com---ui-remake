# 安装与升级

## 全新安装

1. 下载 Release 的扩展 ZIP，解压至准备长期保留的目录。源码 ZIP 供开发使用，不能直接当扩展加载。
2. 在 Edge 打开 `edge://extensions/`，开启开发人员模式。
3. 点击「加载解压缩的扩展」，选择包含 `manifest.json` 的 `zjuers-home-0.4.0` 目录。
4. 点击浏览器「+」，应进入 zjuers.com 并显示定制界面。不要同时启用另一份同类新标签跳转扩展。
5. 需要浏览器启动时也进入首页时，在 Edge「设置 → 开始、主页和新建标签页 → Microsoft Edge 启动时」选择打开指定页面，添加 `https://zjuers.com/`。扩展不会自动修改该浏览器设置。

## 本地壁纸

在设置的主题页选择图片／视频，允许读取所选文件。部分 Edge 版本会要求在独立授权页完成授权；若提供「每次访问都允许」，选择后可在重启恢复。原文件不会复制到扩展包。

使用直接 `file://` 路径时，需要在扩展详情打开「允许访问文件 URL」。文件句柄权限与文件 URL 权限是不同机制，按界面提示处理。权限失效时会提醒并回退默认主题；换设备需重新选文件。

## 保留配置升级

- 建议先在设置 → 数据导出首页配置；此文件不含密码、Key 或令牌，但可能包含个人主题路径和导航，请自行保管。
- 关闭已打开的首页，使用新包内容替换原安装目录中的产品文件，再在扩展管理页点击重新加载。不要卸载原扩展或变更其加载目录，避免扩展 ID 与存储发生变化。
- 如旧目录含本版本已移除的 `migration*` 工具或内置 `assets/wallpaper.mp4`，可以删除这些旧扩展产品文件。不要删除你自己选择的本地媒体原文件。
- 不同扩展 ID 的配置不自动共享。换设备或新安装可导入配置，但账号、天气 Key、CC98 授权及壁纸权限须重新设置。
- 非常早期仅记有 `builtin`、没有路径或文件引用的壁纸无法跨设备恢复，会使用必应；重新选择实际视频即可。已保存完整本机引用的主题会保留。

## 排错

- 仍显示原站：重新加载扩展后刷新已有首页，查看扩展卡片的「错误」及诊断页。
- 信息源不可达：对应控件显示失败／缓存状态；先确认账号、API Host、网络和校内会话。
- 视频静音：确认主题偏好，并注意浏览器可能要求首次用户交互后才允许声音。
- 禁用扩展可停止首页增强与新标签跳转；卸载会移除相应扩展存储，请先导出所需配置。
