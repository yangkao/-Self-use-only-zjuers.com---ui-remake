# MVP 首版安装与审阅

版本 0.1.0；安装包目录 `bin/mvp/`，源码 `srcs/extension/`。本版供用户试用与 UI 审阅，尚未通过本阶段验收。

## 安装

1. 打开 `edge://extensions/`，关闭先前两个验证扩展：入口验证和“ZJUers 新建标签跳转验证”。若同时开启原美化扩展，也先关闭，避免重复修改原站。
2. 保持开发人员模式开启，选择“加载解压缩的扩展”，选本项目的 `bin/mvp/`，确认扩展名“ZJUers 个人首页”、版本 0.1.0。
3. 若 Edge 询问站点访问，允许该扩展访问 zjuers.com。点击“+”，应进入美化后的完整原站。直接打开 https://zjuers.com/ 也应增强。
4. 如需启动 Edge 时打开此页：打开 `edge://settings/startHomeNTP`，在启动时选“打开以下页面”，添加 `https://zjuers.com/`。各 Edge 版本设置文案可能略有差异；不要将扩展内部文件设置为启动网址。设置由用户完成。

第一阶段静态验收版保持在 `bin/preview-approved-2026-10-01/`，可对照外观。后续修订此 MVP 后在管理页刷新扩展，并重新打开原站。

## 试用重点

- 检查主页面、次级页面、侧边设置是否保持已验收的外观，尤其字体、视频、图标和卡片透明度。
- 点击原站导航与新生宝典，悬停原站有说明的链接，检查提示；静态示例中的两个名称已按原站纠正为“拓途浙享”“校网测速”。
- 首次为 Bing；输入词用回车和右侧图标分别搜索；切换引擎，另开主页，检查选择保存。
- 折叠栏目后另开主页检查保存；设置中恢复全部展开；关闭折叠记忆后另开页面应全展开。
- 主界面空白右键进入次级；次级控件外空白左键返回；设置面板外点击先关闭设置；确认视频持续播放、主界面滚动位置保留。
- 天气、课表、考试和作业仍显示示例，配置账户／刷新／清缓存／退出按钮禁用，不应产生真实登录请求。
- 断网后新建标签，应以原生新标签替换失败入口，控制页与其他既有标签保留；原生页刷新不应再跳回原站。联网后新建标签应恢复原站。关闭并重开 Edge，检查启动页和设置保存。

本轮自动检查涵盖导航保留与删改、搜索编码、偏好恢复、启动页与新标签状态及替换顺序。浏览器自动化连接报告 nodeRepl.fetch request failed，尚未完成对本包的真实 Edge 画面与安装测试；入口替换机制的独立诊断版已由用户实测确认可行，但不代替本包验收。

若失败，请给出实际页面、管理页的错误信息和操作顺序；无需提供任何校内账号密码。审阅前不接入后续信息源或发布。

## 0.1.2 加载速度复测

在扩展管理页刷新“ZJUers 个人首页”，确认 0.1.2，再新建标签。此版改为 document_end 注入，模板／设置／样式并行准备，提前开始字体与视频加载，不加入提前遮罩。观察覆盖速度、视频、导航及原有悬停说明。若仍慢，复制扩展选项诊断记录；navigationMs 表示该文档导航开始后的毫秒数，elapsedMs 表示内容脚本启动后的毫秒数，可区分脚本启动晚与资源准备慢。后台记录的 time 含消息与队列延迟，不应用于精确比较。实际提速尚待用户确认。

## 0.1.3 提前准备复测

刷新扩展并确认版本 0.1.3，再另开新标签。此版在 document_start 启动准备，以九栏目加后续原站页脚判断导航解析完整后挂载，不等待整个 DOM 或视频首帧，不加提前遮罩。请比较覆盖与视频出现速度，检查导航及悬停提示。诊断“提前启动资源准备”记录启动时间；“原站导航结构完整”记录导航就绪；“界面显示帧检查点”是双动画帧检查，估计挂载后的绘制时间，不保证等同实际屏幕显示。若仍慢，提供本版诊断记录；性能幅度尚待确认。

## 0.1.4 首屏隐藏复测

刷新扩展并确认 0.1.4，另开新标签。预期原站不再短暂出现，等待期间仅显示深紫底色，个人页面准备完成后直接显示。首页仍加载并提供实时导航；原站其它子页面不隐藏。挂载失败或准备超过 8 秒时解除隐藏并提示，超时不等同断网；真实连接失败仍使用原生页替换回退。请检查首屏闪现、个人页面、导航与断网回退；实际 Edge 视觉效果待确认。
