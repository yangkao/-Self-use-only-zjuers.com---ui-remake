# 隐私与权限

## 数据在何处

扩展没有项目自建的配置上传服务器或遥测。偏好、主题、导航、计时状态、信息缓存以及用户主动保存的账号凭据存放于当前设备的扩展存储中，不通过 Chrome/Edge sync 存储同步。

普通本地扩展存储不是加密凭据库：能读取本机浏览器配置或扩展存储的人可能读取凭据。密码、天气 Key、CC98 令牌仅供可信扩展上下文访问，不提供给原站或内容脚本，不写入配置导出或普通诊断日志。CC98 刷新令牌保存在 local，访问令牌保存在 session；各用户分别授权。

本地媒体以路径／文件句柄引用，浏览器通过用户授权读取。图片／视频原文件不随配置、源码或安装包上传；少量主题缩略图仅在当前页面内存复用。必应每日图片另行采用本机缓存，以便快速恢复及生成配色。

## 外部请求

- zjuers.com：完整原站及导航，仍会运行原站自身代码与资源请求。扩展不能代表原站作隐私承诺。
- cn.bing.com / www.bing.com：默认每日壁纸与图片。搜索按用户选择打开相应搜索平台。
- 用户专属 qweatherapi.com：城市查询及天气，请求携带用户 Key、所选地点。
- v1.hitokoto.cn：哲学分类名句。
- zjuam.zju.edu.cn、zdbk.zju.edu.cn、courses.zju.edu.cn、identity.zju.edu.cn、yjsy.zju.edu.cn：对应学校认证、课程、考试、作业。
- webvpn.zju.edu.cn：独立 WebVPN 登录、转发 CC98 授权及数据请求。
- calendar.celechron.top：公开校历及上课节次时间；当前使用 HTTP，不向此服务发送账号密码。传输可能受网络影响，不视为经过学校签名的校历。

以上服务会收到正常连接所需信息，例如 IP、请求内容与相应认证信息，另受各服务条款约束。安装包不含个人账户或信息源缓存。

## 权限用途

| 权限 | 用途 |
| --- | --- |
| storage | 本机偏好、缓存、计时与主动保存的凭据 |
| alarms | 后台计时到期和提醒 |
| notifications | 用户启用的系统通知 |
| tabs / webNavigation | 新标签跳转、主文档失败回退、打开关联页面与跨标签通知 |
| webRequest | 读取研究生认证跳转信息；不持久化临时票据 |
| 指定站点 host 权限 | 访问上述信息源；和风声明子域权限，实际请求限制为用户配置的专属主机 |
| file:///* | 用户允许时读取本机壁纸路径；句柄读取另外受文件选择授权控制 |

## 清除与备份

设置 → 信息源可清除各项凭据／授权；设置 → 数据可清除缓存。清理只针对本扩展，不主动清除其他学校网页的登录状态。卸载扩展通常移除其本机存储。

配置导出不包含密码、Key、令牌、登录态、信息缓存或计时运行快照；但含用户导航、问候、天气地点与主题配置，可能包含本机路径，请勿随意公开个人导出文件。
