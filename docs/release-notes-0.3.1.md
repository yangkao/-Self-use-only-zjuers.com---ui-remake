# ZJUers 个人首页 0.3.1

第一轮改进正式版，供个人在 Microsoft Edge 中以解压扩展方式使用。

## 更新内容

- 本机主题卡片管理，引用本地图片或视频壁纸，并根据壁纸生成整套界面配色。
- 可调整背景、组件、布局及字体；支持分时问候模板。
- Edge 配套主题导出扩大至标签、地址栏、工具栏、书签栏及新标签页等标准配色字段。主题需在设置中另行下载、手动应用。
- 改进次级页面、设置界面与作业直达链接。

## 安装

下载 `zjuers-home-0.3.1.zip`，解压后在 `edge://extensions` 开启开发人员模式，选择“加载解压缩的扩展”，并选中包含 `manifest.json` 的 `zjuers-home-0.3.1` 文件夹。使用本机壁纸时，在扩展详情开启“允许访问文件 URL”。

已安装用户可将新版文件复制进**原安装目录**并点击原扩展的“重新加载”，以保留扩展身份和当前浏览器配置。请勿先卸载原扩展。详情见仓库中的 `docs/install.md`。
