# 0.4.0

## 本版内容

- 可自定义的两级导航及主界面编辑，区分原站与自定义内容，支持折叠和排序保存。
- 设置分组重做，本机主题缩略图管理、壁纸裁切、配色十六进制编辑及 Edge 静态配色主题导出。
- 课表学期总览、天气详情；WebVPN 自动恢复、CC98 设备授权、未读和十大。
- 紧凑首页组件、就地配置、计时器页面／系统提醒，浏览器关闭期间继续计时。
- 必应每日壁纸作为默认主题；本地媒体由用户选择授权，安装包不含内置大视频。
- 当前主题首帧准备、按需构建、缩略图释放、局部绘制、数据投影和缓存／请求共享等性能优化。
- 修复导航版本冲突后持续无法折叠；正常状态不再因折叠提示“已保存”。

## 交付文件

- `zjuers-home-0.4.0.zip`：可加载的扩展目录，非 CRX／商店签名安装包。
- `zjuers-home-0.4.0-source.zip`：可独立测试和构建的源码与文档，只有本次公开内容。
- `SHA256SUMS.txt`：扩展及源码 ZIP 哈希。
- `release-manifest.json`：扩展逐文件大小与 SHA256。

首次安装使用产品默认设置；没有天气账号／Key、学校凭据、CC98 令牌、信息缓存、个人主题或本机路径。CC98 Client ID 为公开标识，可按需自行更换；公共跨账号授权仍待验证。
