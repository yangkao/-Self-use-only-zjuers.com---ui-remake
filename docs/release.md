# 1.1.2 桌面版

本轮完善柔光交互和控件细节，保留三套材质、既有搜索栏视觉及原有功能。远端 Release 和 Pages 是否更新，以实际发布结果为准。移动端适配尚未完成可行性验证，列为未来更新方向。

## 本版内容

- 导航、小组件、设置及信息卡片统一采用主题色柔光交互，保留图钉、键盘焦点与必要的结构分隔。
- 优化表单、取色滑块和信息条目的留白，减少普通控件的装饰性硬边框。
- 数字输入保留原生校验，使用主题色步进按钮；修复手输后步进并失焦时的同值重复提交。
- 修复课表日历切换月份时意外关闭的问题，并保持月份按钮的键盘焦点。
- 修复内嵌信息源、数据、壁纸编辑器及部分滚动区的柔光裁切，适配临界宽度布局。
- 修复教务认证状态恢复与验证码状态判断，稳定时间数字显示；完善主题取色和部分图标细节。
- 在线演示同步当前 UI，默认称呼为 Zjuer，信息使用合成示例。

## 延续的功能

- 新建主题草稿、纯色背景、视频多帧／区间／单帧取色，候选颜色、锁定、恢复及配色参数。
- 经典样式、适度融合和液态玻璃三种材质，本地 WebGL 渲染器及不可用回退。液态玻璃为试验功能，可能存在渲染滞后。
- CC98 只读专栏，十大、新帖、可搜索版面、个人概览、分类通知、只读会话及签到月历。
- 共享状态的放大视图，桌面窄屏切页和有界长列表；新帖原始偏移上限 500。
- 独立网页演示使用虚构个人资料、消息、天气与课程数据。
- 保留原站增强、导航、计时、天气及校内信息等原有能力。

## 交付文件

- `zjuers-home-1.1.2.zip`：解压后加载包含 manifest.json 的扩展目录。
- `zjuers-home-1.1.2-source.zip`：独立源码、测试、产品文档、演示与 Pages 工作流。
- `SHA256SUMS.txt` 与 `release-manifest.json`：两个 ZIP 与扩展逐文件校验。

首次安装没有个人主题、账号、密码、天气 Key、令牌、缓存或本机壁纸。CC98 Client ID 是公开应用标识，其他用户的授权资格尚未经跨账号验证。

发布包移除开发专用迁移工具、固定迁移 sender、组件展示页与接口探测表单；既有运行所需权限保留。私信不进入持久信息缓存。配置导入不迁移凭据或文件授权。

代码采用 GPL-3.0-only，第三方许可随包保留；液态玻璃的 Apache-2.0 来源见 vendor/Goose-NOTICE.md。外部服务可达性、跨账号认证和低配硬件表现不由本次测试保证。

保留配置升级时保持原扩展加载目录，替换产品文件后重新加载；不要卸载原扩展。性能专项排查暂缓，本次控件修订没有完成低配硬件或真实 GPU 性能认证。
