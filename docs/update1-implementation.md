## 约束
- 基于完整zjuers.com与现有0.2.0，不另建离线导航。
- 原文件壁纸引用仅本机，保存路径/类型，不保存设备名，不复制或长期缓存媒体。
- 一主题包含壁纸、整套颜色、完整视觉参数。默认主题保持旧版外观，恢复默认可用。
- 文件不可读显示主题化报错窗口并使用内置视频及默认配色；保留原配置，单次失败提示一次。
- 视频取色采样少量不同时间帧，图片缩小采样；只在配置/重新生成时运行，日常启动读保存配色。
- 视觉：颜色/背景亮度模糊灰度缩放遮罩暗角/组件透明圆角边框阴影/布局宽度边距间距/字体字号及时间搜索标题尺寸。原生能力，无新增依赖。
- 问候分早上/下午/晚上模板，{称呼}，默认Yangkao，独立本机偏好。
- 页脚“基于 ZJUers 轻首页 · Yangkao个人定制 · 关于”，主次页面随内容排列；原站关于链接+设置关于入口。
- 图标CSS逆时针3.7s；名句正文出处阻止返回；COURSES / 近期作业；homework路由course/{course_id}/learning-activity#/{id}，不细化课程考试。
- Edge独立配色主题生成在设置，用户手动应用，输出无路径/凭据/缓存。使用已验证静态manifest形式。
