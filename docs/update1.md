# 项目第一轮改进的相关内容

## 1.本轮计划加入的功能

1. 在主页面及次级界面版底加入简短的关于此首页的信息。
2. 对于问候：新增对自定义称呼及问候内容的支持。
3. 关于壁纸：除了内置的视频壁纸外，支持自定义壁纸（支持图像与视频）并根据视频自动配置主题色（同步修改首页的主题色及Edge的主题色），主题色在选取壁纸后自动根据壁纸内容生成，但允许用户自行修改，一张壁纸（以本地链接形式存储）与对应的一组主题色和一组视觉设置（见7.）作为一个主题存储。
4. 关于页面中的“ZJUers 轻首页”标签:参考原站的图标动图，修改“ZJUers轻首页”图标为动图样式。
5. 关于课程、考试、作业条目：新增支持点击条目标签时跳转到对应条目的链接（如点击“第三周作业”时跳转到学在浙大中对应条目的页面而不是学在浙大的首页），作业部分已经确认每条作业均有对应页面，课程、考试部分需要ai查询相关信息确定。
6. 对于次级界面的小型修复：（1）一言部分不作为点击跳回主界面的部分（即点击一言部分不要跳回主界面）（2）作业栏“COURSES / 学在浙大”的标题改为“COURSES / 近期作业”。
7. 在设置界面对视觉方面添加更多的调整参数（参考nightTab），对视觉设置单开一栏，同时支持一组全套视觉设置作为一个主题存储。
