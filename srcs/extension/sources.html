来源与权限

页面与设计

基于 ZJUers 轻首页完整页面及 ZJUers 轻首页美化。改动包括导航重组、必应每日壁纸与本机媒体引用、nightTab 风格的时间与搜索、主次切换与侧边设置，以及独立外部信息卡片。素材来源与许可见安装包 ui/media/SOURCES.md。

外部信息

和风天气：实时、三天／七天逐日、24 小时、分钟降水、预警、空气质量与城市查询。详情接口按需加载。使用专属 API Host 与 Key；卡片附接口返回的来源说明。

一言：哲学分类原文，保留返回的作者与出处。

校内接入参考 Celechron 的公开接口行为，自行实现浏览器适配。请求统一认证、本科教务、研究生院与学在浙大。校历和作息来自 Celechron 的 calendar.celechron.top 公共服务；该服务目前使用 HTTP，仅请求公开校历，不向它发送校内凭据。

权限用途

storage：本设备偏好、缓存和用户选择保存的凭据。tabs / webNavigation：新标签跳转、网络失败回退及界面状态。webRequest：仅捕获研究生统一认证跳转的临时票据，不监听普通浏览内容，不持久化票据。

WebVPN：独立账号自动恢复校内访问；新增 webvpn.zju.edu.cn 站点权限。CC98：通过 WebVPN 进行设备代码授权、未读与十大读取，刷新令牌保存在本机 local，访问令牌保存在 session，仅可信扩展上下文可读，不导出、不记录，不需要 Client Secret。验证码和二次验证由用户在原站处理。

站点权限仅用于上述信息源。和风专属域名因每账户不同，声明 qweatherapi.com 子域访问，实际请求限定为用户填写的专属主机。

凭据保存在扩展本地且仅可信扩展上下文可读，不同步、不导出、不记录；普通本地存储并非安全凭据库。退出清除仅处理本扩展数据，不清除你在其他学校网页中的登录。
