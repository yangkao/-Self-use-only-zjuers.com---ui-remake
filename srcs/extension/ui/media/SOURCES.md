# 预览资源来源

- `zjuers.png`：https://zjuers.com/images/ico.png
- `favicon.ico`：https://zjuers.com/images/favicon.ico
- Josefin Sans：Google Fonts 官方仓库，https://github.com/google/fonts/tree/main/ofl/josefinsans ，许可见 `JosefinSans-OFL.txt`。
- Roboto Slab：Google Fonts 官方仓库，https://github.com/google/fonts/tree/main/apache/robotoslab ，许可见 `RobotoSlab-LICENSE.txt`。
- nightTab 的参考源码：https://github.com/zombieFox/nightTab ，GPL-3.0。用于核对时钟、日期、搜索的样式规则及交互；字号、输入高度与间距按其规则实现，参考设置采用 Josefin Sans 展示字体与 Roboto Slab 搜索字体。
- 导航与信息卡片线条图标为本预览绘制。
- 第三版栏目和引擎图标为自定义简化 SVG；求是鹰意象参考浙江大学官方校标说明：https://www.zju.edu.cn/english/2023/0323/c74903a2732011/page.psp 。不作为正式校标使用。
- 第三版将英文和数字统一为 Josefin Sans，Roboto Slab 资源暂保留但不再用于页面。引擎清单核对 https://zjuers.com/js/js15.min.js ，图标不依赖远程加载。

原站图标来源已核对，源页面未单独列出图片许可；此处按用户确认的个人私有使用范围用于本地预览，保留来源记录。

第四版求是鹰引用用户提供的 ../../assets/浙江大学校徽.png，采用 SVG 显示裁切与颜色滤镜，原素材未修改。此图形替换第三版手绘鹰。有道与 CSDN 为简化自定义图标；Github 使用常见章鱼猫标志轮廓，GH镜在相同轮廓上加箭头角标。
